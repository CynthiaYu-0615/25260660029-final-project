# /pypl:evo

## 作用

用户想改进 PYPL 插件的提示词或规则时，运行 evo 流程。系统会在固定基线样例上比较改动前后的效果，最终由用户决定是否采纳、回滚或继续修改。

## 执行流程

1. 调用 `evo` skill。
2. 使用 `$ARGUMENTS` 接收改动说明和基线样例标识。
3. `evo` skill 执行：
   - 记录当前版本。
   - 应用改动。
   - 对基线样例用改动前后各跑一次。
   - 生成对比报告。
   - 询问用户是否采纳。
   - 执行用户决策。
4. 不生成面向用户的 PYPL 研究报告。
