# /pypl:ping

## 作用

手动执行每日检查：核对事件日和重大新闻，决定是否触发生成报告。

## 执行流程

1. 读取 `.pypl/events.json`，检查今天是否为已登记事件日：
   - 如果是，触发 `start` skill 的 Orchestrator 主流程。
2. 搜索 PYPL 新闻，识别裁员、收购、并购、拆分、换 CXO 等重大事件。
   - 如果发现重大事件，触发 `start` skill。
3. 首次运行时，调用 `CronCreate` 注册每日循环检查（7 天后过期，需重新登记）。
4. 返回当天检查结果：是否触发、触发原因、事件列表。
