# Evo 采纳策略（A/B 对比的固定阈值）

本文件是 evo 流程判断「采纳 / 拒绝」候选规则改动的唯一阈值来源，
`pypl/scripts/evo.py` 的 compare 会解析本文中的两个数值并强制执行；
解析失败时 compare 直接报错（fail-closed），不允许绕过。

## 阈值

- `max_false_block_rate = 0`：候选规则的误拦率（该放行的样例被拦的比例）
  不得高于基线规则。基线目前是 0，即候选不允许误伤任何应放行的样例。
- `min_recall_gain = 0`（严格大于）：候选规则的拦截召回率必须**严格高于**
  基线才建议采纳；持平或下降一律拒绝。

## 判定

同时满足以上两条 → 建议采纳（仍需人工批准写入 evals/approvals.json 后
才能 adopt）；任一不满足 → 拒绝，compare 输出中必须写明违反了哪条。

## 指标定义

- 拦截召回率 recall = 应拦截样例中被实际拦下的份数 / 应拦截样例总数。
- 误拦率 false_block_rate = 应放行样例中被错误拦下的份数 / 应放行样例总数。
